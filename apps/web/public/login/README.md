# 로그인 화면 사진 넣는 곳

로그인 화면 왼쪽 슬라이드에 쓰는 사진입니다. 아래 이름으로 넣으면 자동으로 사용되고, 없으면 서비스 화면 그림이 대신 나옵니다.

| 파일 | 어울리는 장면 | 문구 |
|---|---|---|
| `slide-1.jpg` | 헤드셋 상담원이 모니터를 보며 응대 | 실제 고객처럼 반응하는 AI 고객 |
| `slide-2.jpg` | 헤드셋 상담원 클로즈업 (통화 중) | 헤드셋을 끼고, 전화하듯 음성으로 |
| `slide-3.jpg` | 노트북으로 응대하는 상담원 | 끝나면 바로 코칭 리포트 |
| `slide-4.jpg` | 업종별 상담(예: 병원 화상 상담) | 연습할수록 단단해지는 응대 역량 |

현재 사진은 Pixabay 사진(무료·상업 이용 가능)이며, `scripts/grade-login-photos.py` 로 색감을 맞춰 잘라 넣었습니다. 새 사진도 이 스크립트로 처리하면 톤이 통일됩니다.

- 사진을 넣는 칸은 **거의 정사각형~살짝 가로로 긴 모양(1:1 ~ 4:3)** 이고, 칸에 맞춰 가장자리가 잘립니다. 인물은 **가운데**에 두세요.
- 크기는 가로 1600~2400px 정도면 충분합니다. 용량은 1장 500KB 안팎으로 줄여 주세요(JPG 품질 75~80%).
- 글씨가 사진 **아래쪽**에 올라가므로 아래쪽이 너무 복잡하지 않은 사진이 좋습니다.
- **사용 허락(라이선스)을 확인한 사진만** 넣으세요. Unsplash의 콜센터 사진 상당수는 Unsplash+(유료) 라이선스이고, 모델이 나오는 유료 스톡 사진은 구매가 필요합니다. 직접 촬영한 사진은 모델 동의를 받아 두세요.
- 문구는 `src/components/LoginShowcase.tsx` 의 `SLIDES` 에서 고칩니다.
